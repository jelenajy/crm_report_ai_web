# Consumer Hive Premium Web UI 设计规格

日期：2026-09-21  
状态：已确认
适用仓库：`jelenajy/crm_report_ai_web`

## 1. 目标

将现有 C Hive Sage Web 工作台从“浮窗放大版”升级为可长期独立使用的企业级 AI 指标知识工作台。新版继续使用黑金视觉体系，但以深石墨、暖象牙和克制的香槟金建立高级感，避免依赖大面积金色、强发光或堆叠卡片。

页面品牌层级统一为：

- 企业报表系统全称：`Consumer Hive`
- AI 产品名称：`C Hive Sage`
- 中文功能名称：`指标顾问`

本次只重构视觉呈现和相关前端交互，不接入真实模型、检索服务、数据库、工单系统、反馈落库或会话持久化。

## 2. 已确认的视觉方向

采用“高端品牌秩序感 + AI 原生问答”的融合方向：

- 左侧栏使用深石墨黑，承载品牌、报表选择、新建对话、最近对话和知识治理信息。
- 主内容区使用暖象牙色，提高长时间阅读舒适度。
- 香槟金仅用于品牌标识、选中态、关键动作和轻量分隔。
- 主内容减少独立卡片数量，通过留白、字体比例和细分隔线建立层级。
- 主对话仍维持低学习成本：选择报表、点击推荐问题或直接输入问题即可开始。
- 不使用外部字体、图片或前端依赖，确保单文件离线可打开。

## 3. 页面结构

### 3.1 左侧栏

从上到下包含：

1. Consumer Hive 品牌区。
2. C Hive Sage 产品名和“指标顾问”中文名称。
3. “新建对话”按钮。
4. 当前报表选择器。
5. 当前知识包状态。
6. 最近对话列表。
7. `Knowledge Governance / Consumer Hive · CRM Analytics / 已审核指标知识体系`。

桌面端固定显示左侧栏。移动端沿用现有覆盖式抽屉、遮罩关闭、Escape 关闭和焦点恢复机制。

### 3.2 主内容区

顶部展示：

- `SAGE / 当前报表名称`
- 当前报表对应的 Knowledge 状态

初始欢迎态展示：

- 英文眉题：`CONSUMER HIVE INTELLIGENCE`
- 中文主标语：`让每个指标，都有据可循。`
- 单行说明：`请围绕所选报表询问指标逻辑；知识未收录时可在本页标记待补充。`
- “猜你想问”推荐问题列表
- 底部输入框

回答态展示：

- 用户问题
- C Hive Sage 回答
- 回答结论、口径说明和知识来源
- 可展开的知识依据
- 后续已有追问与反馈能力

## 4. 品牌标识

Logo 使用无硬质外框的八角北极星：

- 十字四个主方向使用长尖角。
- 四条对角线使用较短尖角。
- 中心保留深色圆核和细金描边。
- 不保留双层菱形边框。
- 使用 3.6 秒低频闪耀动效，仅在周期末短暂出现缩放、柔光环和星芒。
- `prefers-reduced-motion: reduce` 时关闭动画，静态显示完整北极星。

## 5. 控件设计

### 5.1 新建对话

- 使用约 15px 圆角。
- 深色半透明渐变背景。
- 暖金低对比边界。
- 保持整行点击区域和键盘可访问性。

### 5.2 报表选择器

关闭状态：

- 使用约 18px 圆角胶囊外观。
- 深石墨半透明底色。
- 克制的暖金边界和箭头。

展开状态不能继续使用系统原生 `<select>` 弹层，因为其颜色、圆角和边框无法稳定匹配产品视觉。改为定制 listbox：

- 菜单为不透明深石墨背景。
- 约 16px 圆角。
- 不显示外边缘线。
- 选项使用约 10px 内圆角。
- 当前项使用低透明度暖金背景和金色状态点。
- 支持鼠标选择、键盘上下方向键、Escape 关闭和焦点返回。
- 点击菜单外部关闭。

报表选项保持：`Customer Type`、`Product`、`Member Tier`、`Binding`、`NPS`。切换后必须同步更新顶部报表名、知识包名称、输入提示、知识依据标题和推荐问题。

### 5.3 输入框

- 采用约 17px 圆角。
- 降低整体高度和边框对比度。
- 输入提示文字与输入区尺寸保持协调。
- 发送按钮为圆形暖金渐变按钮。
- 保留 Enter 发送、Shift+Enter 换行、字符限制和自适应高度等现有行为。

### 5.4 知识依据

“查看知识依据”必须是可操作按钮，而不是静态文字：

- 默认收起。
- 点击后展开知识包、口径主题和依据摘要。
- 再次点击收起。
- 同步 `aria-expanded`、`aria-controls` 和内容 `hidden` 状态。
- 箭头随展开状态旋转。
- 历史回答继续使用各自的报表快照，不能被后续报表切换改写。

## 6. 页面语言调整

所有用户可见页面文案移除以下表达：

- `原型演示`
- `原型`
- `模拟效果`
- `模拟提交`
- `模拟导航`
- 其他会让页面显得像内部演示稿的文字

改写原则：

- 欢迎区只说明能力和知识范围。
- 回答区强调“已审核知识”和“正式业务口径”。
- 知识未收录时使用中性表达：暂未找到可靠依据，在本页标记待补充，并显示刷新后重置的本页临时编号。
- 未接入真实后台的能力不能在页面中伪装为已完成外部提交；技术边界在 README 和需求文档中明确说明。
- HTML 的 `<meta name="description">`、标题、Toast、历史会话、知识缺失、跨报表引导和反馈提示均纳入文案清理范围。

## 7. 行为保持与兼容性

以下现有能力必须保持：

- 五报表切换与上下文快照。
- Customer Type 已有问答和四类问题路由。
- 推荐问题随报表更新。
- 新建对话。
- 输入字符统计和发送控制。
- 追问、反馈、Toast 和最近对话。
- 移动端侧栏、遮罩、Escape 和焦点管理。
- 生产环境边界阻止 `.git`、隐藏文件和校验脚本被 Web 服务公开。

视觉重构不得改变知识路由和回答分类的业务语义。

## 9. 验收标准

### 9.1 视觉与文案

- 页面明确展示 `Consumer Hive`、`C Hive Sage` 和`指标顾问`。
- 桌面端呈现深色左侧栏与暖象牙主内容区。
- Logo 为无硬框八角北极星，并支持减少动态效果偏好。
- 新建对话、报表选择器和输入框使用统一圆润语言。
- 用户可见界面不存在“原型”或“模拟”字样。
- 说明文案在设计基准宽度 659px 下保持单行；更窄设备允许安全换行，不得产生水平溢出。

### 9.2 交互

- 定制报表菜单的展开、选择、外部点击关闭、方向键和 Escape 均可用。
- 报表切换同步更新所有报表上下文文案。
- 推荐问题和手动输入均能进入回答态。
- “查看知识依据”可展开和收起，ARIA 状态同步。
- 新建对话能恢复欢迎态。
- 移动侧栏交互保持可用。

### 9.3 验证

- 既有需求同步校验通过。
- 静态回归校验通过。
- 浏览器运行时回归通过。
- 新增对定制报表菜单、知识依据展开、八角北极星和页面禁用词的覆盖。
- 在桌面宽度、842×837 和 659×837 三种视口完成视觉检查。
- 浏览器控制台无错误。
